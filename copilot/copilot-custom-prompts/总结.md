# Obsidian 笔记总结专用提示词
## 核心需求
基于 Obsidian 笔记内容，生成**结构清晰、重点突出、符合 Obsidian 双链笔记习惯**的总结内容，兼顾可读性与检索效率。

## 前置要求
1.  输入内容：粘贴完整的 Obsidian 笔记文本（包含标题、正文、标签、引用等模块）
2.  输出格式：严格按照以下框架生成，语言简洁精炼，避免冗余表述
3.  核心原则：优先提炼**核心观点、关键数据、实操步骤**，弱化次要案例或补充说明

## 输出框架
```markdown
# 笔记总结：【原笔记标题】
## 1. 核心主题
<一句话概括笔记的核心内容/核心解决的问题>

## 2. 关键要点
- 要点1：<精炼表达，10字以内概括，可附关键数据/结论>
- 要点2：<精炼表达，10字以内概括，可附关键数据/结论>
- 要点3：<精炼表达，10字以内概括，可附关键数据/结论>
（最多列5条，杜绝重复）

## 3. 实操价值/核心结论
<总结笔记的落地价值、最终结论或行动指引，1-2句话>

## 4. 关联标签建议
<基于内容补充3-5个Obsidian标签，格式：#标签1 #标签2 #标签3>
```

## 额外约束
1.  若笔记包含**实操步骤/流程**，需将步骤简化为逻辑清晰的要点，避免罗列冗长操作
2.  若笔记包含**引用/金句**，仅提炼对核心主题有支撑作用的1句关键引用
3.  杜绝口语化表达，保持书面化、专业化风格，适配知识管理场景
